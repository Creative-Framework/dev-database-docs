# Getting Started

## Installation

```bash
npm install dev-database
```

## Basic Usage

### JavaScript
```js
const DevDatabase = require('dev-database').default;

const db = new DevDatabase('database.json');

db.set('name', 'Ahmed');
console.log(db.get('name')); // 'Ahmed'
```

### TypeScript
```ts
import DevDatabase from 'dev-database';

const db = new DevDatabase('database.json');

db.set('name', 'Ahmed');
console.log(db.get<string>('name')); // 'Ahmed'
```

## Configuration

You can configure the database by passing an object instead of a string:

```ts
const db = new DevDatabase({
  filePath: './data/mydb.json',  // Database file path
  autoSaveInterval: 300,         // Debounce save interval (ms)
  pretty: true,                  // Pretty print JSON
  autoCreate: true,              // Auto-create file & directories
  separator: '.',                // Nested key separator
});
```

## Core Methods

```ts
// Set a value
db.set('key', 'value');

// Get a value (with optional default)
db.get('key');
db.get('missing', 'fallback');

// Check if key exists
db.has('key'); // true

// Delete a key
db.delete('key'); // true

// Clear all data
db.clear();
```

## Dot Notation

Dev-Database supports deep access to properties using dot notation:

```ts
db.set('users.123.name', 'Ahmed');
db.set('users.123.level', 10);

db.get('users.123.name');   // 'Ahmed'
db.has('users.123.level');  // true
db.delete('users.123.level');
```
