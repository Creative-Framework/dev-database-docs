# Collections

Collections provide a MongoDB-like interface for managing arrays of documents inside your database.

```ts
interface User {
  name: string;
  age: number;
  role: string;
}

const users = db.collection<User>('users');
```

## Inserting Data

```ts
// Insert single document
users.insert({ name: 'Ahmed', age: 20, role: 'admin' });

// Insert multiple documents
users.insertMany([
  { name: 'Sara', age: 25, role: 'user' },
  { name: 'Ali', age: 18, role: 'user' },
]);
```

## Finding Data

You can use query operators such as `$gt`, `$lt`, `$in`, `$ne`, etc.

```ts
// Find with query operators
users.find({ age: { $gt: 18 } });
users.find({ role: 'admin' });

// Sort and limit
users.find({}, { sort: { age: -1 }, limit: 10 });

// Find exactly one
users.findOne({ name: 'Ahmed' });

// Find by ID
users.findById('abc-123');
```

## Updating Data

You can update fields directly, or use update operators like `$inc`, `$set`, `$push`, `$pull`.

```ts
// Direct field replacement
users.update({ name: 'Ahmed' }, { age: 21 });

// Increment values
users.update({ role: 'user' }, { $inc: { age: 1 } });

// Push to an array
users.update({ name: 'Sara' }, { $push: { badges: 'vip' } });
```

## Deleting Data

```ts
users.delete({ role: 'user' });
users.deleteById('abc-123');
```

## Available Query Operators

| Operator   | Description              | Example                          |
|------------|--------------------------|----------------------------------|
| `$gt`      | Greater than             | `{ age: { $gt: 18 } }`          |
| `$gte`     | Greater than or equal    | `{ age: { $gte: 18 } }`         |
| `$lt`      | Less than                | `{ age: { $lt: 30 } }`          |
| `$lte`     | Less than or equal       | `{ age: { $lte: 30 } }`         |
| `$ne`      | Not equal                | `{ role: { $ne: 'admin' } }`    |
| `$in`      | Value in array           | `{ role: { $in: ['a', 'b'] } }` |
| `$nin`     | Value not in array       | `{ role: { $nin: ['x'] } }`     |
| `$exists`  | Key exists               | `{ email: { $exists: true } }`  |
| `$regex`   | Regex match              | `{ name: { $regex: '^A' } }`    |
